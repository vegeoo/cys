# DemoControl

Supabase 연결 상태와 관계없이 결로를 직접 시험하는 사용자 선택 모드다.

- 화면 오른쪽 아래에 `데모 모드` 전환 버튼을 항상 표시한다.
- Supabase 설정이 없어 자동으로 데모가 켜진 경우에도 버튼으로 현재 상태를 확인할 수 있다.
- 데모 모드를 켰을 때만 슬라이더가 보인다.
- `input type="range"`, 최소 0, 최대 100, step 1
- 라벨은 `데모 습도`, 현재 퍼센트를 함께 표시한다.
- 데모 readings는 실제 센서 readings와 별도로 유지한다.
- 변경 시 실제 Reading과 같은 `{ value, created_at }`을 데모 readings에 추가한다.
- 센서 연결 실패가 발생해도 데모 슬라이더와 결로 애니메이션은 영향을 받지 않는다.
- 키보드 조작과 44px 터치 영역을 지원한다.
